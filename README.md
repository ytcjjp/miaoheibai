# 喵黑白

项目统一存放于 `D:\子弦\miaoheibai`，新增文件及构建输出均使用该目录。APK 输出到项目根目录；本地截图、缓存和工具链保存在项目内的 `.toolchain` 等忽略目录。

按用户要求，每次完成修改、验证并出包后，自动提交本次相关源码与 APK，并推送到当前 Git 分支的 `origin`。项目工作约定见 `AGENTS.md`。

原生 Android 应用工程。首页可上下滑动，当前包含“倒计时”工具：自定义小时/分钟/秒、3 分钟与 1 分 30 秒快捷计时、实时显示、暂停/继续/取消、最近使用。后台计时由前台服务维持，并在通知中提供暂停和取消操作；精确闹钟用于到点唤醒。计时结束震动三次，每次 5 秒，间隔 1 秒。启动图标使用 `app/src/main/icon-source.png` 中的图片。

## 构建 APK

应用内新增每日幸运数字：江苏体彩 7 位数和双色球各一组。首次进入或跨天时生成新结果，当天结果保存在本机，点击刷新可重新随机生成，动效约 2 秒。7 位数每位独立取 0–9，允许重复并保留前导零；双色球红球从 1–33 不重复选 6 个并升序显示，蓝球取 1–16。红色表示普通号码，蓝色表示双色球蓝球。使用系统 Web Crypto 随机数，无网络依赖，不提供官方开奖结果或桌面组件。

号码规则：[江苏体彩网](https://api.js-lottery.com/wfzq/seven/wfzq/cms/post-13905.html)、[湖北福彩](https://www.hbfcw.cn/cfb/wfgz/202009/t20200921_386233.shtml)。

打开软件时会自动随机播放内置轻柔 BGM，并沿用保存的音量。已有音乐播放时继续当前曲目；页面切换、后台返回和旋转屏幕不会重新触发播放。可在小黑猫页面或音乐通知中暂停及切歌。

桌面小猫组件的播放按钮向默认音乐播放器发送播放请求，音符按钮打开播放器。点击组件音乐入口会停止本应用 BGM，避免同时发声。播放器不支持标准播放请求时会打开播放器供手动选曲；有多个播放器且未设默认时，系统会提示选择。

需要 JDK 17 和 Android SDK Platform 35 / Build-Tools 35.0.0。这台电脑的工程目录内已经准备好这些工具。在 Windows PowerShell 中运行：

```powershell
.\build-apk.ps1
```

输出为工程根目录的 `喵黑白-debug.apk` 和对应版本的 APK。也可以用 Android Studio 打开本目录构建。将 APK 传到手机安装；首次启用倒计时时，按系统提示允许“闹钟和提醒”权限。Android 13 及以上也请允许通知权限，以便在后台查看计时和通知操作。手机需具备震动硬件且未禁用震动。最低支持 Android 8.0（API 26）。
